# まなびの相棒手帳

人間ドック後の健康相談に必要な知識を、文章入力なしで学習・記録できるモバイル向けPWAです。

## 主な機能

- 相棒「こむぎ」による今日のおすすめ
- 健康相談向け7分野・24枚の知識カード
- 5・10・15・25分の学習タイマー
- 設定時間を超えた学習も、終了操作まで実時間で自動記録
- iPhoneショートカット「まなび通知」1つで、選択した5・10・15・25分の標準タイマーを同時開始
- カードと時間に合わせた生成AI学習プロンプトの自動生成・ワンタップコピー
- 理解度4段階のワンタップ記録
- 分野別スキルガーデン
- スタンプカレンダーと自動学習履歴
- 日別・週別・月別で過去へさかのぼれる学習時間グラフ
- 相棒の経験値・レベル表示
- 端末内保存とオフライン起動

## 学習分野

- 血圧・代謝
- 脂質・肝臓
- 女性の健康
- 胃・十二指腸
- 大腸
- 腎臓・血液
- 生活習慣

## データと注意事項

- 学習記録はブラウザの `localStorage` に保存します。
- iPhoneでバックグラウンド中も確実に知らせるには、初回に「まなび通知」ショートカットを1つ作成します。ショートカット内でクリップボードから数字を取得し、その最初の項目を分単位の標準タイマーへ渡します。
- 実在患者を特定できる情報は入力しない前提です。
- 本アプリと生成AIの回答は学習支援用であり、医療判断・診断・治療指示や勤務先の手順の代替ではありません。
- 判定値や対応は、最新の公的ガイドライン、年齢・性別、施設基準、勤務先の規程を確認してください。

## ローカル確認

静的ファイルのため、任意のHTTPサーバーで配信して確認できます。

```sh
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。
