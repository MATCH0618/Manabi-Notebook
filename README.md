# まなびの相棒手帳

病院勤務の保健師が、文章入力なしで継続学習を記録できるモバイル向けPWAの試作版です。

## MVP機能

- 相棒「こむぎ」による今日のおすすめ
- 病院保健師向けの仮知識カード18枚
- 5・10・15・25分の学習タイマー
- 理解度4段階のワンタップ記録
- 分野別スキルガーデン
- スタンプカレンダーと自動学習履歴
- 相棒の経験値・レベル表示
- 端末内保存とオフライン起動

## データと注意事項

- 学習記録はブラウザの `localStorage` に保存します。
- 実在患者を特定できる情報は入力しない前提です。
- 知識カード名は画面検証用の仮内容であり、医療判断や院内手順の代替ではありません。
- 正式版では勤務先の規程・最新ガイドラインを確認してカード構成を精査します。

## ローカル確認

静的ファイルのため、任意のHTTPサーバーで配信して確認できます。

```sh
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。
